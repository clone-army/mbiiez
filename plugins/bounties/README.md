# Bounties Plugin

**Requires the `caded.i386` engine** from [clone-army/OpenJK](https://github.com/clone-army/OpenJK). Needs the **Credits** plugin.

`!bounty <player> <credits>` puts a price on someone's head; whoever kills them collects it. `!bounty` alone
lists the active ones.

Engine: `g_economyBountyEnable 1` (set by this plugin).

Also editable under **Settings** in the web panel.
