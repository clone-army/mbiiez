# Shop Plugin

**Requires the `caded.i386` engine** from [clone-army/OpenJK](https://github.com/clone-army/OpenJK). Needs the **Credits** plugin.

`!buy` - weapons, gadgets, size changes and ammo for credits. Every item's price is a setting
(`cvars.g_shopCost_<item>`; 0 takes it out of the shop).

Engine: `g_economyShopEnable 1` (set by this plugin).

Also editable under **Settings** in the web panel.
