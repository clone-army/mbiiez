GUID Bans

A GUID is the ID a player's copy of the game sends when it connects. It stays the same when they change IP or name. A banned GUID is refused on every server, and anyone already playing with it is dropped within a few seconds. Banning an IP on the IP Bans page also bans every GUID seen on that IP in the last 30 days, and unbanning the IP lifts them again.
